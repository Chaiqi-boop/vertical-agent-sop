# 垂类智能体项目实施 SOP

18 页网页演示，覆盖项目签约后的合同交接、需求梳理、POC 验证、开发集成、UAT、试运行、验收与运营移交，并明确市场、销售、产品、实施、研发及客户之间的协作边界。

采用 guizang-ppt-skill 的瑞士风版式：克莱因蓝、黑白网格、轻字重标题与 ASCII 动效。

## 查看方式

通过本仓库的 GitHub Pages 网站查看，或下载 `index.html` 后在浏览器中打开。建议使用横屏全屏模式。

## 演示操作

- `←` / `→`：翻页
- `Home` / `End`：首页 / 末页
- `N`：查看或关闭本页讲稿
- `ESC`：页面索引
- `B`：动态 / 静态模式切换
- `F`：全屏

## 文件说明

- `index.html`：18 页演示成品，包含图片、主要脚本及随页讲稿。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

本版是 HTML 网页演示，不是原生 PowerPoint 文件。讲稿与页面内容一并公开。
